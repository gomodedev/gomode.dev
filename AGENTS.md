# Go Mode product website

This repository owns gomode.dev, a static product website hosted with Cloudflare Workers assets. The standalone [Go Mode repository](https://github.com/gomodedev/gomode) owns the Android shell, Go host contracts, browser integration, MCP/OAuth transport, voice gateway, and capture producer.

## Source and validation

Read `/home/user/src/gomode/README.md` and the relevant implementation before changing product claims. Read current [Cloudflare documentation](https://developers.cloudflare.com/workers/static-assets/) before changing Worker configuration.

Install hooks with `scripts/install-git-hooks.sh` before changes. Run `pnpm run fix`, `pnpm run verify`, and `pnpm run build`. Verify desktop/mobile layouts, keyboard navigation, image loading, console errors, and 404 responses in a browser after presentation changes.

## Captures

Go Mode produces native WebP captures in `e2e/screenshots/android`. Real host frontend captures come from caic’s `e2e/screenshots/frontend` and mddb’s `e2e/screenshots/docs`; these use sample data from their screenshot suites. Publish the captures `public/index.html` references with `uv run --locked python scripts/publish_screenshots.py` from this website checkout. `public/favicon.svg` is generated from the Android launcher icon; publish it with `uv run --locked python scripts/publish_favicon.py ../gomode.dev` from the gomode checkout and never edit it by hand. Builds consume committed captures and never invoke the producer or download tools. Do not hand-edit generated captures.
