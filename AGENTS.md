# Go Mode product website

This repository owns gomode.dev, a static product website hosted with Cloudflare Workers assets. The standalone [Go Mode repository](https://github.com/maruel/gomode) owns the Android shell, Go host contracts, browser integration, MCP/OAuth transport, voice gateway, and capture producer.

## Source and validation

Read `/home/user/src/gomode/README.md` and the relevant implementation before changing product claims. Read current [Cloudflare documentation](https://developers.cloudflare.com/workers/static-assets/) before changing Worker configuration.

Install hooks with `scripts/install-git-hooks.sh` before changes. Run `pnpm run fix`, `pnpm run verify`, and `pnpm run build`. Verify desktop/mobile layouts, keyboard navigation, image loading, console errors, and 404 responses in a browser after presentation changes.

The site intentionally uses a new asset-only Worker. Preserve the old waitlist Worker’s persisted data; follow README.md when switching the custom domain. Do not add destructive Durable Object migrations.

## Captures

Go Mode produces `e2e/screenshots/android/manifest.json`. Use `pnpm run screenshots --source ../gomode/e2e/screenshots/android` to import current assets. Builds consume committed captures and never invoke the producer or download tools. Do not hand-edit generated captures or their manifest.
